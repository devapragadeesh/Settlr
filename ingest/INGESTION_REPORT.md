## What each adapter drops (named, not silent)

- **xlsx**: Sheets beyond the first are never read; only the bank role (reference, value_date, narration, amount) is populated.
- **camt053**: Ccy (no second-currency field exists), CdtDbtInd as a standalone flag (folded into the amount's sign), non-Ntry statement-level data (GrpHdr, Bal, account identifiers).
- **mt940**: The funds code, the transaction type code (NTRF etc.), the bank-assigned '//' reference when an owner reference is present, and :86: structured subfield tags.
- **jsonl**: Nothing -- items round-trip as opaque dicts, unlike the bank-only formats above.
